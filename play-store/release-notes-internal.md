# GHOSTNET — Android internal testing release notes (draft)

**Version:** 3.8 development Android foundation / replace version code and release number with actual signed build metadata.

### What's included

- Offline-first cyber-themed single-player clicker game.
- Simulated target breaches, equipment upgrades, hosts, and multiple progression paths.
- ZERO DAY research and permanent prestige perks.
- Item Ascension progression up to level 9,999.
- Daily login rewards, quests, and special events.
- Local save data and optional Google Play Games integration points.

### Important limitations for testers

- Google Play Games cloud saves require final Play Console configuration and SHA setup before functioning.
- Rewarded ads may use Google test ads only; real AdMob release IDs are not configured.
- Premium Store real-money checkout is **disabled** in this build; displayed product prices are previews, not purchasable items.
- This is an early Android build; report UI jumps, crashes, lost saves, purchase preview confusion, and performance stalls.

### Tester focus

1. New guest start and progression while offline.
2. Upgrade purchases, MAX, 9,999 ascension and ZERO DAY.
3. Daily reward cannot be claimed more than once per day.
4. Touch target remains stationary during counters and notifications.
5. Save export/import and recover after app restart.
6. Optional Play Games sign-in / cloud save once test IDs are configured.

**Do not claim all Google services are operational without real-device confirmation.**
